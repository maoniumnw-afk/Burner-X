# GitHub Cloud Superpower & PPT Visual Bridge

> **Why GitHub instead of direct HTTP to `ais-pre-...run.app`?**
> AI Studio preview domains (`*.run.app`) are protected by Google's browser session authentication gateway and return HTTP 404 to unauthenticated CLI `curl` requests. By contrast, both your local workstation and the AI Studio Cloud Lead Architect container have direct, unrestricted `HTTP/2 200` access to **GitHub (`git` & `api.github.com`)**.

## 1. Directory Protocol in Repository (`maoniumnw-afk/username-repo-name`)

Ensure these folders exist in your shared GitHub repository:
- `.cloud-bridge/inbox/` — **Local Agent -> Cloud Lead Agent**: Write `REQ-xxx.md` task files here and `git push`.
- `.cloud-bridge/outbox/` — **Cloud Lead Agent -> Local Agent**: Completed architectural blueprints and task receipts (`REQ-xxx.md`).
- `.cloud-bridge/assets/` — **Cloud Lead Agent -> Local Agent**: High-resolution 8K PPT images (`.jpg` / `.png`) generated by the Cloud Lead Agent's native `generate_image` tool.
- `.agent/skills/<skill-slug>/SKILL.md` — **Cloud Lead Agent -> Local Agent**: Ready-to-use Superpower skills automatically committed by the Cloud Lead Agent.

---

## 2. How Local Antigravity CLI / DeepSeek Submits a Request

### A. Request a New Superpower `SKILL.md`
Create `.cloud-bridge/inbox/REQ-104-custom-skill.md`:

```markdown
---
id: REQ-104
type: superpower_spec
status: pending
source_agent: antigravity-cli-local
skill_slug: api-contract-guard
target_path: .agent/skills/api-contract-guard/SKILL.md
---

# API Contract & Schema Validation Superpower

## Prompt / Requirement
Please write a strict SKILL.md for local DeepSeek Flash agents to validate Zod schemas and OpenAPI contracts before modifying backend routes.

## Local Project Context
TypeScript + Express + Zod monorepo
```

### B. Request High-Resolution PPT Slide Visuals
Create `.cloud-bridge/inbox/REQ-105-ppt-slides.md`:

```markdown
---
id: REQ-105
type: ppt_asset
status: pending
source_agent: antigravity-cli-local
aspect_ratio: 16:9
target_path: .cloud-bridge/assets/slide-02-pipeline.jpg
---

# Slide 02: Zero-Latency Neural Telemetry Pipeline

## Prompt / Requirement
Clean scientific isometric rendering of a high-throughput telemetry ingestion pipeline with brushed titanium nodes and optical glass data conduits on a dark slate background, studio rim lighting, 16:9 keynote presentation graphic.
```

### C. Push Request to GitHub
```bash
git add .cloud-bridge/inbox/
git commit -m "bridge(inbox): submit request to AI Studio Cloud Lead Agent"
git push origin main
```

---

## 3. Pulling Completed Images & Superpowers Back to Local

Once the Cloud Lead Agent processes the inbox and pushes back to `maoniumnw-afk/username-repo-name`, simply run:

```bash
git pull origin main
```

All generated `SKILL.md` files will be directly in `.agent/skills/` and all 16:9 PPT images will be ready in `.cloud-bridge/assets/`!
