# 《持械入宋》全景人物关系图谱与势力博弈 Superpower 纲领

## 1. 任务背景与目标 (Context & Objective)
用户要求基于爆火历史穿越巨作《持械入宋》（现代5人特战小队携械穿越至北宋末年宣和年间）构建深度的人物关系图谱与跨维度博弈规则纲领。
类似此前针对《冒姓琅琊》门阀士族关系图谱的深度突破，本次需要云端主架构师提炼一套面向「现代军事体系与宋末冷兵器政军生态碰撞」的 Superpower 技能纲领：
- 梳理穿越小队 5 人内部战术协同与分工闭环；
- 刻画小队与清河村地方势力、北宋朝堂宗室、南宋名将（岳武/岳飞）及外部金夏敌对势力的动态博弈网；
- 提炼现代科技/工业降维打击（武器弹药消耗、工业复刻、医疗外贸、情报网）的系统化规则体系。

## 2. 核心人物与势力拓扑 (Character Entities)
1. **现代穿越小队（核心五人组）**：
   - **林昭**：队长/战术指挥，京籍，冷峻果决，掌握单兵突击、近身搏杀与特种指挥。
   - **谢长风**：副队长/狙击手，东北籍，远程精确打击与重火力压制。
   - **马振邦**：军械工程师/海归，军工研发担当，负责枪弹维护、改良连弩、铸造青铜佛朗机火炮。
   - **王浩川**：通信与情报官，广东籍学霸，走科举打入东京汴梁建立情报枢纽，结识昭华帝姬与名将。
   - **陈素**：战地医官，湘妹子，负责现代外科创伤救护、伤寒药理及开发女性护肤品商贸。
2. **北宋地方与民间盟友**：
   - **秦红缨**：英气女将/民军领袖，小队早期生死与共盟友（第六季为掩护林昭壮烈牺牲）。
   - **秦荣**：关中豪强盟友，遭伏击遇害成为小队出兵讨伐西夏的关键导火索。
   - **狄知县**：地方主政官，清河村早期庇护与官方背书者。
3. **朝堂宗室与历史名将**：
   - **岳飞（化名岳武）**：相识于微末，武穆精神与现代国防战术理念碰撞。
   - **昭华帝姬 / 赵宋皇室**：汴梁政治联络枢纽，小队政治合法性与羁绊。
4. **外部强敌**：
   - **西夏铁鹞子 / 金国完颜氏铁骑**：冷兵器巅峰冲击力量与游牧骑射战术。
